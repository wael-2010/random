# Wael 's Randomizer

this mod turns mc into a very hard and funny game .

by making all crafting recipes changes every time you try to craft.

not just that , it also randomize all block Drops.

and the best part is the Randomized Chunks.

Every 15 seconds the chunk  the player is in will get randomized and swap places

with another random chunk

# Commands

you can start the minigame by /start 
and stop it by /stop

# Random Recipes 

all recipes gets randomized and changes every tick , you cant make the same recipe twice
